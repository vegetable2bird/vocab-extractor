# 生词提取器 · Vocab Extractor

面向**中英夹杂的外刊文章**（含中文译文）的生词提取工具。粘贴或导入文章后，点选不认识的英文单词，一键生成生词列表，拿去交给 AI 解析音标 / 词性 / 释义 / 例句。

## 功能

### 1. 多种导入方式

| 方式 | 说明 |
| --- | --- |
| 粘贴文本 | 直接贴外刊文章（中英对照亦可） |
| 上传文件 | `.txt` / `.md` / `.pdf`（PDF 走 PDF.js，浏览器内抽取文字，需联网一次） |
| **截图 / 图片** | **Ctrl+V 直接粘贴截图**，或点按钮选图、拖拽图片；浏览器内 OCR 识别 |
| 拖拽 | 把文件直接拖进输入框 |

### 2. 点选生词 → 生词本

- 文章中每个英文单词都可点击，点一下加入生词本，再点取消
- 生词本自动去重并统计出现频次
- 支持「按字母 / 按词频」排序切换

### 3. 智能预选（免去逐页手点）

- 内置约 2000 个常用英文词表 + 词形还原（自动识别 `runs→run`、`cats→cat`）
- 一键把**非常用词按词频排序**全部预选进生词本，只需删掉已认识的词
- 可设「最少出现 N 次」阈值，只留反复出现的高价值词

### 4. 导出

- 复制纯单词列表
- **复制 AI 提示词**（含要求音标 / 词性 / 释义 / 例句的完整模板）
- 下载 `.txt`

## 快速开始

双击 `index.html` 用浏览器打开即可，无需安装、无需后端。

> 首次使用 PDF 或图片导入时需联网一次（加载 PDF.js / Tesseract.js 语言包），之后可离线使用。

## 段落结构还原

外刊 PDF 常把一自然段拆成多个视觉行，直接抽取会糊成一坨。本项目用**行距**判定段落边界：

- **PDF 侧**（`rebuild.py`）：按坐标聚行 → 行距中位数作基准 → 超基准 1.3 倍即断段
- **图片 OCR 侧**（`index.html` 内 `reflowByBoxes`）：不依赖 Tesseract 的纯文本，而是取**词框坐标**自行聚行判段

## OCR 修复流水线（可选，用于 PDF 中嵌为图片的生词）

部分外刊 PDF 的重点生词是**嵌入图片**而非文字层，常规提取会漏掉。流水线脚本：

| 脚本 | 作用 |
| --- | --- |
| `extract_words.py` | PyMuPDF 定位词级图片块 → RapidOCR 双尺度投票识别 → wordfreq 自动采纳；增量存 `slots.json`，支持断点续跑 |
| `make_sheets.py` | 把待校对/可疑项拼成校对图版 |
| `validate_corr.py` | 交叉校验人工校对结果（语言冲突 / 相似度过低 / 缺失） |
| `rebuild.py` | 合并文字层与识别结果，按坐标行**还原段落**，输出完整全文 |

数据文件：`slots.json`（词位坐标 + OCR 结果）、`corrections.json`（人工校对）、`flagged.json`、`review_ids.json`。

### 依赖

```bash
pip install pymupdf rapidocr-onnxruntime wordfreq onnxruntime==1.16.3
```

> 注意：`onnxruntime` 需固定 1.16.3，新版会导致 OCR 初始化 `bad allocation`。

## 已知限制

- OCR 对倾斜、模糊、低分辨率截图识别率会下降，建议正对截取清晰图片
- 专有名词（品牌名、人名）会被当作生词，导出前扫一眼删掉即可
